# Answer-first outline rules

Lengths below are heuristic, design choices of this skill, to calibrate.

## Opening

- 40 to 60 words, directly under the H1.
- Answers the query in the first sentence, in plain words, with the key figure or condition if
  there is one (taken from the facts table).
- No preamble ("In this article…", "Have you ever wondered…").
- Says for whom the answer changes, if it does ("For teams under 10 people, …").

## Headings

- H2s are questions a reader would type or ask, in the reader's words; H3s only when a section
  splits into distinct cases.
- Order follows the reader's path: answer, how/conditions, options, pitfalls, decision.
- No heading copied from a page read; build them from the matrix rows.

## Each section

1. First sentence answers the heading's question.
2. Then the evidence: fact from the facts table (with its source), example, step, or first-hand
   material.
3. Then the nuance: exceptions, conditions, what changes the answer.

The brief gives, per section: the heading, the one-sentence answer, the facts to use (by facts
table id), the information gain if any, and a target length range.

## Other rules

- Every figure in the outline points to a facts table row; no figure without a source.
- Unconfirmed information (launches, rumours) is phrased as unconfirmed, with the date it was
  last checked.
- If the user has a commercial tie to a product mentioned, the outline includes a disclosure
  line near the top and before the first mention.
- The FAQ answers in 1–3 sentences each and does not repeat H2s word for word.
- Title options: the main query or a close form near the start; meta options: the answer in
  short form. Lengths are display constraints of search engines that change; verify current
  guidance from the engine's documentation at run time if the user asks for exact limits.
