# Red flags

Any one excludes a target. Record the literal evidence (quote, URL, date) in the tracker `notes`
and set `status=excluded`.

## Venue red flags

| Red flag | What to look for |
|---|---|
| Paid link placement | "sponsored post", "do-follow link for $", price list for links, without the link being marked as paid |
| Reciprocal link required | "a backlink to us is required for a free listing", badge-for-listing schemes |
| Link farm / no editorial choice | thousands of unrelated categories, everything accepted instantly, pages full of outbound links |
| Thin or spun content | near-duplicate pages, content unrelated to the domain name |
| Dead venue | no activity in 12+ months, broken submission form |
| Rules exclude the site | commercial products banned, paid products banned, AI text banned (no draft) |
| Scraped or expired-domain site | content unrelated to its history, previous owner's topic visible |
| Asks for credentials or access | admin rights, password, API key to "verify" |

## Offer red flags (the user asks "is this worth it?")

- A fixed number of links for a price ("200 links for 50 €").
- Guaranteed "DA/DR" or ranking increases.
- Private blog networks, "high-authority guest posts" sold in packages.
- Review or rating packages, upvote packages, "AI mention" packages.

Answer plainly: it buys exposure to a link-scheme or fake-engagement policy. Name the rule the
user would break (search engine spam policies on link schemes; the platform's own rules on
reviews or votes) — read and date the current wording before quoting it — and give the
legitimate route from this skill.

## Platform rules to quote

Do not quote a platform's rule from memory. Open its current policy or community rules page,
quote the sentence, give the URL and the reading date.
