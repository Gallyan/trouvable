# What to ask the user to export

From Search Console, **Performance → Search results**:

1. Set the date range (last 3 months is a good default; for a trend, enable *Compare*).
2. Keep search type *Web* unless the question is about Discover or News.
3. Click **Export** and download as CSV or Excel. The download holds one table per tab
   (queries, pages, countries, devices, dates…); the queries and pages tables are the two needed.
4. Send the file as-is (ZIP, XLSX or the CSV files) and list the brand terms.

For a query-to-page view (needed to detect pages competing for one query), the user can
filter the Performance report on one query and export the Pages tab, query by query.

Verify these menu names against the live interface before quoting them to the user:
the interface changes and is localised.
